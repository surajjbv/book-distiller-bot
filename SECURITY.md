# Security policy

## Reporting a vulnerability

Please report security problems privately: on GitHub, open the **Security** tab of this repository and choose
**Report a vulnerability**. Please don't open a public issue for them.

This is a personal project maintained on a best-effort basis. Reports are usually acknowledged within a week.

## Supported versions

Only the latest `main` is supported; fixes are not backported.

## Scope

Everything runs locally on the owner's Mac. Personal values (accounts, tokens, names) live in gitignored files
(`.env`, config) and a pre-commit check keeps them out of the repository. If you find personal data or a secret in
this repository or its history, please report it the same way.
